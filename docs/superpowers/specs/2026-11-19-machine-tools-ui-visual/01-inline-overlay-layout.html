How should inline tools fit into the Home Machine Overlay?

The three launcher buttons (GRIND, SCALE, POUR) keep their existing shape and row. Tapping a tool opens it inline inside the overlay without losing any controls, and an expand (↗) action opens the Full Tool View. Use the simulation controls below to test Pour's full parameter density, the on-brand dot-wave transitions, the Stopping… feedback state, and the Mac-style head-shake when trying to collapse while running.

TOOL: PHASE:
A

Drawer Below Existing Readings

Keep WATER, MODE, and REFRESH visible above the buttons; expand the inline tool below.

Tradeoff: Zero shift to existing panel rows above the buttons, but pushes the recipe library furthest down when Pour (5 controls) is open.
B

Focused Tool Mode Swap RECOMMENDED

When a tool opens, collapse WATER / MODE / REFRESH / EASY MODE into one crisp top status line so the buttons + tool stay compact.

Tradeoff: Fits Grind, Scale, and full 5-control Pour cleanly without burying the library list below; closing the tool restores full vitals + Easy Mode.
C

Compact Side-by-Side Mini Bench

Readout + action pinned left, dense parameter ladder stacked right to minimize vertical height.

Tradeoff: Shortest vertical footprint for Pour, but leaves narrow room at large OS text / Dynamic Type sizes.
