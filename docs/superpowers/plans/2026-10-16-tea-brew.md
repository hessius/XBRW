# Tea Brew Recording and Display Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give tea a truthful fill/steep/release/drain presentation, remove coffee-only actions and figures, and establish the cause of incomplete multi-steep recordings before changing machine behavior.

**Architecture:** Snapshot beverage identity into each new record. Use a shared record-based handoff eligibility rule and keep tea presentation separate from coffee arithmetic. Capture and replay the machine's actual tea events before implementing a tea phase adapter; neither elapsed time nor the reported `done` outcome alone proves a steep completed.

**Tech Stack:** Expo SDK 57, TypeScript, React Native, Tamagui, expo-sqlite, Jest's iOS/Android projects and async React Native Testing Library.

**Approved spec:** `docs/superpowers/specs/2026-10-16-tea-brew-design.md`.
